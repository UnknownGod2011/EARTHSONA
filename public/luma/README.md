# Luma sprite assets

EARTHSONA uses Luma’s original blue crystal artwork from the local November 14, 2026 keyboard.wtf production site snapshot. The full source is a 1536 × 2288 WebP atlas with 192 × 208 frame cells. Its SHA-256 is `3968af492f7be6cb2c8c1b62d7b81544311af29aeaf2b2a79358594cc39cda81`, matching the installed Codex Luma v2 sprite.

The deployed WebP files preserve the pixels and transparency of six strips from the atlas. The companion uses `idle.webp` (row 0, six frames), `run-right.webp` and `run-left.webp` (rows 1 and 2, eight frames each), and `wave.webp` (row 3, four frames). The guide also uses `react.webp` (the jump on row 4, five frames) and `listen.webp` (the waiting pose on row 6, six frames). Reduced motion shows a still.

The artwork originated in the participant’s earlier AI-assisted Luma project and is credited as AI artwork in the guide. The guide plays the scientific sounds locally in the browser and supports optional prerecorded narration.
