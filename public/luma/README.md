# Luma sprite assets

EARTHSONA uses Luma’s original blue crystal artwork from the local November 14, 2026 keyboard.wtf production site snapshot. The full source is a 1536 × 2288 WebP atlas with 192 × 208 frame cells. Its SHA-256 is `3968af492f7be6cb2c8c1b62d7b81544311af29aeaf2b2a79358594cc39cda81`, matching the installed Codex Luma v2 sprite.

The deployed WebP files preserve the pixels and transparency of four strips from the atlas. `idle.webp` uses row 0 and six frames, `wave.webp` uses row 3 and four frames, `listen.webp` uses the waiting row 6 and six frames, and `react.webp` uses the jump row 4 and five frames. The guide waves on entry, uses the listening pose during playback, and jumps on the result. Reduced motion shows a still.

The artwork originated in the participant’s earlier AI-assisted Luma project and is credited as AI artwork in the guide. The guide itself uses local browser playback and optional local English speech synthesis.
